- [x] 2026-10-16 09:20 PDT - `apps/api/src/routes/documents.ts:182`, `:194-217` - OnlyOffice callback JWT is not bound to the callback body, and the editor page hands out a token signed with the same secret

    - VM public IP changed since Cloudflare A record was set (`gcloud compute instances describe` vs Cloudflare DNS)
